    Each automated route uses a separate browser context. The keyboard executor accepts only a short list of key presses. It cannot click, directly fill a control, or move focus through script.

    Completion comes from the practice store’s recorded outcome. The model cannot award itself a pass. Replay repeats saved actions in a new context.

    Current scope: one owned practice store. No external websites, accounts or purchases. Fixture replay is scripted; Meta mode requires explicit server setup. This candidate is not ready for public release.
