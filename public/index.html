    FOR PRODUCT AND ENGINEERING TEAMS

    Put a keyboard journey
    on every pull request.

    A team runs its own app on loopback in GitHub Actions, marks the important controls with four stable data attributes, and receives a bounded JSON evidence artifact. Muse Spark chooses only allowlisted keys. Playwright executes them. The customer app alone reports completion.

    Read integration guide ↗Copy GitHub workflow ↗
    See the exact integration contract

    journey.config.json

    {
  "schema_version": 1,
  "name": "customer-checkout",
  "url": "http://127.0.0.1:3000/checkout",
  "task": "Choose Blue, then add it to the cart"
}

    Four stable attributes in the customer app

    data-journey-target="blue"
data-journey-selected="Blue selected"
data-journey-complete="true"
data-journey-outcome="Blue added to cart"

    Then run npm run journey:run -- --config=journey.config.json. The Meta key stays in the CI secret store; it is never part of this file.

    1. 1Run your app locallySame-origin loopback only. Remote URLs and embedded credentials are rejected; use an owned test app with no real accounts or purchases.
    2. 2Expose a small contractTarget, selection, completion and outcome stay deterministic.
    3. 3Review the artifactActions, states, request count and limitations attach to the pull request.

    Implemented scope: reusable customer-owned local targets, keyboard lane, eight requests maximum, no automatic retry. Contract and browser acceptance are automated; no customer production benchmark is claimed.

    EVIDENCE BEFORE A VERDICT

    Make the journey
    inspectable.

    Each automated route uses a separate browser context. The keyboard executor accepts only a short list of key presses. It cannot click, directly fill a control, or move focus through script.

    Completion comes from the target app’s recorded outcome. The model cannot award itself a pass. Replay repeats saved actions in a new context.

    Current scope: owned practice fixtures and a reusable loopback CI contract. No arbitrary public websites, accounts or purchases. Fixture replay is scripted. Bounded Muse Spark runs are verified; public live AI stays off.
